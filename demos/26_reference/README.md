# Module 26 — reference implementation

**Author material. Not part of what students get handed, and not a model solution to
be published.**

It exists for one reason: `26_project/check.py` states fifteen acceptance criteria,
and criteria nobody has satisfied are criteria that might be unsatisfiable. This is
the implementation the numbers in the brief were measured from, and continuous
integration runs the check against it:

```console
uv run 26_project/check.py demos/26_reference
```

If that ever goes red, the brief is wrong and not the student.
